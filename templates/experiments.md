# Experiments

Hypotheses tested by measurement — recorded whatever the outcome. Research profile.

**A refuted entry is never deleted and its number is never reused.** It is the most
valuable thing this register produces: an evening of work that will not be spent again.

Open an entry with `python tools/new_experiment.py`, not by editing this file — the tool
allocates the number, writes the index line, and refuses to proceed without a
prediction. That refusal is the only enforcement rule H7 has.
